
## 工作原理

脚本流程：

1. **匹配文件夹**：按 `TARGET_KEYWORDS` 用关键词匹配仓库下的顶层文件夹
2. **插入章节页**：为每个文件夹生成一个临时 md（内容为 `# 文件夹名`），作为 EPUB 的一级标题
3. **处理每个笔记**：
   - **图片**：URL 解码 → 尝试多种路径 → 补全扩展名 → 复制到临时目录并重命名为 `img_00001.jpg` → 重写 md 中的引用
   - **标题**：所有 `#` 降两级（因为文件夹 = H1，文件名 = H2）
   - **文件名**：作为 `## 笔记标题` 插入到内容开头
4. **调用 Pandoc**：
   - `--epub-chapter-level=2`：遇到 H2 就分一个新 HTML 文件
   - `--toc-depth=2`：目录显示到文件名这一层
   - `--resource-path=_temp_epub_build`：从临时目录读取图片
   - `--css=epub-style.css`：应用自定义样式
   - `--embed-resources`：图片打包进 EPUB


## 样式表

`epub-style.css` 采用中文书籍的常见排版：

- 正文段落 **首行缩进 2 字符**（`text-indent: 2em`）
- 正文衬线体（宋体系），标题无衬线体（黑体系）
- 行距 1.75，两端对齐
- 图片居中，代码块灰底，引用块左侧灰色竖线

## 自定义

### 调整文件夹顺序

修改 `TARGET_KEYWORDS` 列表的顺序：

```python
TARGET_KEYWORDS = [
    "思考",       # 先输出
    "财富",
    "反焦虑"
]
```

### 调整笔记顺序

在笔记文件夹里给 md 文件加数字前缀：

```
001_想先出现的笔记.md
002_第二篇.md
003_第三篇.md
```

脚本会自动按数字排序。

### 添加封面

在 `metadata.yaml` 里加一行：

```yaml
cover-image: cover.jpg
```

然后把 `cover.jpg` 放到脚本目录。

### 调整目录显示层级

修改 Pandoc 命令里的 `--toc-depth=N`：

- `--toc-depth=1`：只显示文件夹
- `--toc-depth=2`：显示文件夹 + 文件名（推荐）
- `--toc-depth=3`：再展开到笔记内的一级标题

### **如需取消首行缩进**

把 `p { text-indent: 2em; }` 改为 `text-indent: 0;` 即可。


## **针对 iBooks 的夜间模式适配**

Apple Books 在夜间模式下会强制覆盖正文颜色（甚至包括背景色、边框色），普通 CSS 无法生效。

因此 `epub-style.css` 中额外加入了针对 iBooks 的规则：

- 使用 `ibooks-dark-theme-use-custom-text-color` 类名，让 iBooks 停止接管容器内文字的颜色
- 用 `@media (prefers-color-scheme: light)` 和 `@media (prefers-color-scheme: dark)` 分别定义日间、夜间的文字颜色
- 对需要高亮的文字（如 `.highlight`）单独设置颜色，保证在日间和夜间都能看清

### **使用前提**

- 读者必须在 iBooks 中选择 **“原始字体”**，否则所有自定义颜色都会被覆盖
- 容器级类名会接管容器内**全部**文字颜色，普通正文也需要显式指定颜色，否则可能继承高亮色
- iBooks 夜间模式**不触发**标准 `prefers-color-scheme: dark` 媒体查询，所以夜间颜色必须靠该类名解锁，不能只靠媒体查询

详细机制、测试结论与选择器写法，见仓库中的 [iBooks 自定义字体颜色配置文档](./iBooks%20自定义字体颜色配置文档.md)。

## 常见问题

### Q1：脚本提示"文件夹不存在"

**原因**：全角/半角字符（竖线 `|` 和 `｜`、空格和全角空格）肉眼难以区分。

**解决**：使用 `TARGET_KEYWORDS` 关键词匹配（只需包含部分名字即可），不要写全名。

### Q2：图片全部找不到

**原因**：Obsidian 笔记里的图片路径可能是相对于仓库根目录，而非相对当前 md 文件。

**解决**：脚本已内置多种路径尝试（相对当前文件、相对仓库根目录、绝对路径、补全扩展名）。如果仍然找不到，运行脚本后看终端的 `⚠️ 缺失` 输出，找到引用路径格式。

### Q3：EPUB 里图片是空的（`Images` 文件夹为空）

**原因**：`--resource-path` 没指向临时目录。

**解决**：确保 Pandoc 命令里是 `--resource-path=_temp_epub_build`（或 `+ TEMP_DIR`）。

### Q4：生成的 EPUB 只有 3 个 HTML 文件

**原因**：Pandoc 默认按 H1 分章，文件夹是 H1，笔记是 H2，所以只分了 3 章。

**解决**：使用 `--epub-chapter-level=2`（Pandoc 3.x）让 Pandoc 遇到 H2 也分章。

### Q5：`Unknown option --standalone--css`

**原因**：在脚本里加参数时漏了逗号，导致两个参数被拼成一个字符串。

**解决**：确保 `"--standalone",` 结尾有逗号。

### Q6：图片缺失怎么办？

脚本会生成 `缺失引用报告.txt`，列出所有找不到的图片引用及其所在文件。回到 Obsidian 中修复后重跑脚本即可。
